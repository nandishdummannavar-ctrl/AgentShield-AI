# AgentShield-AI
AgentShield AI – An AI Agent Security &amp; Control Center that evaluates AI agent actions, assesses security risks, and blocks unauthorized operations using a rule-based security engine. Built with Python and Streamlit.

**AI Agent Authorization & Security Prototype**

AgentShield AI is a Python-based security prototype designed to control AI agent actions through authorization rules and security checks.

##  Features:
- AI agent action authorization
- Security rule validation
- Unauthorized action detection
- Automated security tests
- Interactive Streamlit web interface

##  Technologies Used:
- Python
- Streamlit
- Pytest
- Git and GitHub
